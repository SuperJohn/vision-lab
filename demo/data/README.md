# Demo data (Vision Lab)

Synthetic / privacy-screened sample metrics and gallery captions for the Cloudflare Pages showcase.

- `data.json` — canonical sample for local tooling and `HL_DATASET_URI=file://…/demo/data/data.json`.
- The Pages-served copy lives at `site/assets/data.json` (same content; the static site fetches it at runtime as a relative asset).

Do not put real camera captures, family media, or PII here. Media under `site/assets/` was VLM-screened and hand-checked before commit.
